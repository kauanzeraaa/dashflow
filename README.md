# Dashflow

> Transformando o Planilhas Excel em inteligência de negócios.

## 🚀 Sobre o Dashflow
O **Dashflow** é um sistema completo focado no tratamento, organização e análise de dados comerciais. Projetado para tirar as planilhas do escuro, ele centraliza informações de clientes, consultores e contratos, gerando insights estratégicos automatizados. É a ponte perfeita entre a operação comercial diária e a consolidação da Ciência de Dados corporativa.

---

## ✨ Funcionalidades em Destaque
*   **Pipeline Analítico:** Limpeza, tratamento e padronização automática de dados brutos utilizando algoritmos em Python.
*   **Geração de Insights:** Identificação de padrões de contratação, tendências de faturamento e oportunidades comerciais por nível de cliente (A, B e C).
*   **Visão 360º da Carteira:** Gestão relacional clara conectando Consultores, Clientes, Contratos e o catálogo de Serviços.
*   **Telemetria Integrada:** Registro de auditoria completo para monitorar o upload de novas planilhas e o status de execução dos modelos.

---

## 🛠️ Stack Tecnológico
*   **Frontend:** Construído com Vue 3 e Vite, estilizado com Tailwind CSS para garantir uma interface ágil, moderna e responsiva.
*   **Backend:** API robusta, escalável e segura desenvolvida em Java utilizando o ecossistema Spring Boot.
*   **Ciência de Dados:** Processamento pesado e análises preditivas/descritivas feitas com scripts em Python (Pandas).
*   **Banco de Dados:** Armazenamento relacional e estruturado utilizando PostgreSQL.

---

## ⚙️ Como Executar Localmente
*   **Pré-requisitos:** Certifique-se de ter Node.js, Java (JDK 17 ou superior), Python 3 e o PostgreSQL instalados na sua máquina.
